# Wadhwani Foundation Demo Checklist

Project title: College Complaint System

Suggested description: A role-based college complaint platform where students report problems and deans review, resolve and document preventive actions to reduce repeated issues.

Final public URL after deployment:
https://collegecomplaintsystem.in

Demo flow:
1. Register as Student.
2. Raise a complaint.
3. Logout.
4. Login as College Dean.
5. Review the complaint.
6. Set status to In Review.
7. Enter dean response, root cause and preventive action.
8. Mark resolved.
9. Login as Student and show the resolution.

Use fictional demo data; do not expose real student personal information.
